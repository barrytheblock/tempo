# tempo ♫

Tempo is an open-source YouTube Music statistic tracker, completely finetuned with streaks, charts, themes and share features.

 
## Features
1. Over 9+ panel themes
2. Customizable panel hotkey, notifications and data management
3. Artist streaks
4. Generatable image that shows all your stats, ready to share
5. No download required, copy and paste into tampermonkey


## Manual Installation
1. Install the **tempo.js** file
2. If you haven't installed tampermonkey, get it [here](https://www.tampermonkey.net/#download)
3. Head over to [YouTube Music](https://music.youtube.com)
4. Go to Extensions > Tampermonkey > Add new script
5. Paste the content of the **tempo.js** file
6. Click File > Save
7. Then refresh YouTube Music
8. Click Right Shift to open the panel
9. All set!

## Direct Install
You can also directly install the script using Greasy Fork.
1. Head over to our [page on Greasy Fork]([https://airstudios.nl/muffincord](https://greasyfork.org/en/scripts/591320-tempo))
2. Click **Install this script**
3. Click **Install** one last time
